\section{Introduction}
\label{sec:introduction}

With the rapid development in AI Agent, Large Language Models (LLMs) have demonstrated substatntial 
capacities in software engineering tasks \citep{Liu2026LLMAgent}. However, The ability to generate 
functionally correct code does not demonstrate a comprehensive understanding of program behavior. A program generated
by LLM might pass the test suit while the model still fails to reason the program's intermediate states, control flow, boundary
conditions \citep{Chen2025REval}.
